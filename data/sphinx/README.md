# The Sphinx — evidence set

- dem/       ArcticDEM (or Copernicus) GeoTIFF tile covering the feature
- line/      descent.gpx (or any track; also accepts .geojson)
- photos/    face photos; geotagged ones register automatically later
- reports/   trip reports as .md: paste text, keep source URL + date
- pin.md     the summit coordinates + where they came from

Transfer from the iPad: download in Safari, then upload via your SSH app
(scput/upload in Blink, Termius SFTP upload, or plain scp) to this directory.
