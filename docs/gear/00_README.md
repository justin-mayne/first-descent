# Modern Ski, Skimo, Climbing & Winter Camping Game Reference Pack

This reference archive contains technical specifications, authentic modern brand benchmarks, visual/3D modeling details, and game design mechanics (weight, warmth, stamina, durability, and movement modifiers) for a ski, ski mountaineering (skimo), alpine climbing, and winter expedition video game.

## Contents
1. `01_Modern_Ski_and_Skimo_Hardware.md` - Alpine, Freeride, Touring, and Ultra-light Skimo Race hardware, bindings, boots, skins, and avalanche rescue gear.
2. `02_Technical_Clothing_and_Layering.md` - Base layers, mid-layers, 3L hardshells, skimo race suits, expedition down parkas, footwear, and protective accessories.
3. `03_Alpine_Climbing_and_Glacier_Gear.md` - Ice axes, boot/ski crampons, harnesses, ropes, crevasse rescue hardware, and rock/ice protection.
4. `04_Winter_Camping_and_Bivy_Equipment.md` - 4-season expedition tents, bivy sacks, sleeping systems (R-values & temp ratings), liquid fuel/canister stoves, and snow-melting logistics.
5. `05_Game_Systems_and_Mechanics_Integration.md` - How to translate real-world gear into video game systems (Up-track vs. Downhill transitions, Thermoregulation/Sweat vs. Freezing, Pack Weight & CoG physics).
6. `gear_master_database.csv` & `gear_master_database.json` - Structured item database with real-world weights (g), costs ($), warmth/protection ratings, and gameplay stat modifiers ready for engine import.
